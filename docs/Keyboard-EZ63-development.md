## 0.1.0 实现边界

`plugins/Hhub.Keyboard` 是独立设备插件，主体无品牌专用修改。Windows SetupAPI 枚举 HID 接口，以零访问权限打开元数据句柄，核对真实 VID/PID，读取 HID 描述符与 PnP 父链。只在完整 USB 物理实例明确时归并；父链缺失时保留独立接口，不按产品标识猜测归并。匹配目标仅接受完整物理/成员实例，断开或歧义返回失败。存在 FF60/61 时仅标为“已识别”，`protocolVerified` 与 `settingsWritable` 始终为 false。端点错误与不存在分开显示，未知电量不伪造。

内嵌 WebUI 提供当前设备信息、按键测试和可展开的接口详情；支持主题、缩放和小窗口。页面所有输入只在本地处理，失焦清除按下态。Esc 退出；Fn 不提供模拟测试；不宣称测试能区分多把键盘或代表硬件触发/延迟结果。

## 后续协议实现

1. 用此型号配置接口的描述符、固件版本与官方工具合法获得的通讯记录建立样本；区分 GET 查询与 SET、保存、复位和 bootloader 命令。
2. 先实现版本/能力和当前配置读取，定义报文长度、报告 ID、命令号、字节序、分包、校验与响应关联，再用假传输验证超时、陈旧响应、断开、多设备与错误码。
3. 实现设备实例绑定的传输与独占控制，写入前重新枚举和校验端点；更新清单权限与资源声明。不能把任意网页消息映射到原始 HID 报文。
4. 按顺序接入键位、灯光、触发行程/RT。每次写入必须由独立 GET 回读确认，无法确认则标为未确认，不展示成功。协议未验证的选项不放入 UI。
5. 宏、配置、场景和高级磁轴行为在能力确认后接入；固件刷写、恢复出厂、校准不在首轮范围。
