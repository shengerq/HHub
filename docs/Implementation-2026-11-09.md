# 统一插件体系首轮实现记录

本轮先核对现有设计，发现可执行合同、认证准入、空主体发布及数据迁移边界尚未落地。已经开始实现第一阶段，不再仅停留于设计文档。以下不代表主体验收完成。

## 已落地

- 独立 PluginContracts、PluginSdk、UnifiedHost，分别承担合同、插件侧流程与主体侧认证/存储/进程。没有加入旧包强兼容适配层。
- 清单 schema 2 与 hhub.plugin/1 预览协议，设备/功能共用模型；值支持有界结构对象和数组。
- CMS 全负载认证、固定认证身份、包及安装内容完整性、已知撤销、更新版本检查。
- 临时安装后提交、个人预设独立保存、未知数据格式拒绝覆盖、卸载可选择保留数据。
- 进程握手、串行请求、完整读取、写后验证、SDK 恢复与未知状态保护、超时终止及退出清理。
- Hhub.App 增加 UseUnifiedHost 构建入口，生成独立 Hhub.Preview，不加载旧业务窗口；新数据目录与既有版本隔离。旧构建入口保留用于对照，不做运行协议转换。
- 新发布脚本只发布主体，不调用监测、音频和 Windows 设置构建。模拟包单独生成、明确标注，不自动安装。测试认证密钥不作为正式项目密钥。
- SDK 实现文档、真实结构 schema、模拟后端模板和认证工具。详见 sdk/v1/README.md。

## 验证

- 新主体 Release 编译和模拟认证版自包含发布成功。构建为 0 警告、0 错误；无 bundled-plugins 目录。
- 新统一解决方案 Release 构建通过；保留的旧 Hhub 主体 Debug 构建也通过，均为 0 警告、0 错误。编译通过不等于旧全量检查通过。
- 统一基础检查现为 120 项通过，使用最新发布的 Hhub.Preview.exe 共享启动器运行。覆盖同型号多目标隔离、断线重连先读后写、目标独立预设、服务声明解析、更新启动验证与数据回退；真实子进程分别在更新切换前后退出，验证重启恢复。损坏的恢复快照会阻止激活并保留日志；不兼容旧预设的更新被拒绝。新增预设应用、插件/目标匹配、禁止临时任务写入、多值读回及部分失败逆序恢复；一项恢复失败也继续尝试其余项。日志为工作区根目录 hhub-unified-shared-tests.log。
- 桌面实测：预览首页显示 0 安装/0 运行，插件空状态正确，系统选包窗口能够打开并取消，预览正常退出。系统 PickerHost 窗口不能由本次自动化准确绑定，未将 GUI 选包安装链路标记为已通过；底层安装与进程路径由自动检查覆盖。
- 只启动了本轮预览及模拟后台，没有发送真实硬件命令，没有更改厂商设置，没有更新现有 Hhub 用户数据。

## 已知未完成

当前公共协议仍为预览子集。目标发现和按目标操作已实现，身份稳定性尚需实机验证；服务已实现声明、版本匹配和提供者选择，跨插件调用路由仍待完成。插件页面合同、取消/幂等与增量订阅仍待实现。当前 UnifiedWindow 是接口验收界面，不替代用户已选定的 Hhub 成熟页面设计；旧 MainWindow 源码保留，后续把验证完成的公共边界整合进正式页面。插件更新启动验证与失败数据恢复、当前目标默认预设批量应用已实现；完整受管进程树治理、正式数据迁移器及多预设命名管理仍需完善。新增应用预设按钮及编辑框同步尚未完成桌面点击验收，不继承此前空主体界面验收结论。

主题包按用户决定仅保留后期提案，不开发、不作为本阶段接口和验收前置条件。当前继续聚焦主体和已有功能。

主体安装器、自身认证更新和完整卸载尚未接入新主体，不能把插件卸载通过当作主体卸载完成。旧 0.5 Core 全量测试存在此前记录的清理失败，本轮未把它伪报为通过，也未用旧测试替代新主体门禁。

正式认证密钥及撤销清单未配置。没有测试认证参数的构建不信任任何包，保持拒绝；模拟构建只信任当次测试签名身份，不能当成正式分发。

下一项主任务：把目标/服务/页面和操作恢复合同补齐，并完善主体安装更新/卸载及预设迁移；主体验收完成前继续不迁移真实插件。不得将 SDK 预览子集提前冻结为外部稳定版本。
