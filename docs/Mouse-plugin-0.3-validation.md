# 鼠标插件 0.3.0：原生驱动调节项与分页

日期：2026-11-04。目标为雷柏 VT3S MAX，有线与 2.4G。

## 布局与功能

依据用户提供的五张原生驱动截图，将 DPI、按键、宏定义、性能、传感器、电源与外观、固件与恢复、诊断放入八个主分区。性能、传感器、电源使用二级分页。主程序内嵌 WebUI，页头左侧为连接状态，右侧为鼠标名称与有效电量；缺少电量读数时隐藏。

增加独立 C# 寄存器编解码，保留共享寄存器相邻字段与保留位。扩展写入保存首次原值，回读确认；恢复时也逐个回读扩展原值。支持完整 DPI 档位表修改与档位数恢复。宏仅为本地草稿，不执行或上传。
