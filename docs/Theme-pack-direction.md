# 轻量主题包方向（设计提案，尚未实现）

状态：按用户决定延期，只保留提案。当前不开发主题包，不把主题合同、资源插槽或主题验收加入本阶段；优先完成主体及当前支持功能。

目的：允许联名外设保留视觉氛围，同时复用 Hhub 主体控件和设备插件功能，不为每款外设重复开发完整页面。主题不承担驱动、音频或系统设置功能。

## 最小范围

主题包采用数据与静态资源：清单、受限颜色/圆角/间距参数、设备图、横幅和背景。第一版不接受脚本、可执行文件、外部 XAML、任意控件模板、远程资源、视频和持续动画。主题通过统一模板的指定插槽呈现，参数范围由主体校验。

全局主题负责主体配色；设备主题仅作用于指定设备页面。设备插件声明稳定的 deviceModelId、控件能力和设备图热点；主题以该标识匹配，不绑定某版驱动 DLL。主界面结构、导航、认证标识、权限提示和危险操作确认由主体保留。用户选择优先于设备建议，缺图、版本不兼容或包损坏时回退默认外观，设备功能仍可操作。

主题包单独按需下载安装、更新与卸载；不复制一份运行时、不启动后台进程，不在安装设备插件时强制安装联名素材。包签名复用已有项目认证基础，但使用独立包类别及校验规则，不伪装成 function 插件。具体主题清单与包格式待主体阶段实现后公开，不提前作为稳定 SDK。

## 资源边界

安装前限制文件类型、条目数、总大小、图像尺寸与解码像素预算；拒绝路径穿越、链接及未列入签名的文件。仅解码当前可见页需要的图像，离页释放大图，缓存有上限；窗口进入后台不执行主题动画任务。以实际内存与启动测试决定预算，不承诺零内存开销。

主题颜色不能覆盖系统高对比度模式与焦点提示；保证文字可读、缩放后可用。联名资源需标明作者与授权来源，软件不得自动搬运厂商或 IP 素材作为可再分发资源。

## 与 UI 完善的关系

先完成基础页面的信息层级、布局、状态、键盘操作及缩放，再加入主题参数和插槽。主题解决风格与氛围，不能替代功能页质量。当前 UnifiedWindow 仍是接口验收界面，不能据此认定最终 Hhub 外观已经退化或已经完成。
