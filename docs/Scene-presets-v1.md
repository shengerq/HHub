# 场景预设 v1

首次初始化或从旧版本迁移时，提供日常、音乐、游戏三个场景（112 × 112 逻辑像素的卡片）。已有同 ID 或同名场景会复用，保留场景动作、规则及外设绑定。迁移前在用户数据目录 backups 下备份场景和偏好文件；通过 scenePresetVersion 标记完成，后续不会在启动时恢复用户主动删除的场景或规则。

音乐前台程序：QQMusic（QQ 音乐）、cloudmusic（网易云音乐）。游戏前台程序：cs2（Counter-Strike 2）、r5apex / r5apex_dx12（Apex Legends）。场景的应用选择器显示友好名称，匹配使用不区分大小写的程序名称，而非窗口标题。程序无需预先安装；安装并运行对应程序后，规则即可识别。

规则仅匹配前台窗口，后台音乐、启动器或反作弊程序不触发切换。预设优先级为 0，已有自定义应用规则优先；已分配或禁用的应用规则不覆盖。首次迁移启用自动切换并以日常为基础场景，后续继续尊重手动锁定及自动切换设置。

预设只配置场景与应用识别，不自动生成外设配置或修改设备参数。用户保存和绑定设备配置后，由现有场景流程执行。

Apex 程序命名参考 [EA 官方排错页](https://help.ea.com/en/articles/apex-legends/error-codes/)；CS2 的程序标识可见 [Valve 项目中的启动记录](https://github.com/ValveSoftware/Proton/issues/7068)。程序名称存在版本差异时，可以在场景中编辑应用识别规则。
